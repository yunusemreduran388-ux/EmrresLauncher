# ⛏️ EmresLauncher

Modern, lightweight, offline-capable, open-source Minecraft launcher featuring the built-in Modrinth mod manager.

##  Features
- **Modrinth Integration:** Directly search and download mods such as Sodium, Iris, and JEI using the launcher via a single click.
- **Graphics Optimization for Arch Linux + Hybrid GPUs:** Unique graphics optimizations specifically made for Arch Linux and NVIDIA GPUs.
- **Low-Resource Consumption:** Lightweight and fast user interface powered by Avalonia UI and .NET.
- **Mod Management:** Enable/disable the installed mods in one-click (.disabled).
